HTML Meta Tags Audit

A simple audit of important meta tags used in an HTML document.

1. Introduction

Meta tags provide information about an HTML document. They are placed inside the <head> section and are generally not displayed directly on the webpage.

2. Meta Tags Audit Table

Audit of HTML Meta Tags
Meta Tag Purpose Status
charset Defines the character encoding. Present
viewport Helps control page dimensions on mobile devices. Present
description Provides a summary of the webpage. Present
keywords Lists relevant page keywords. Present
author Identifies the content author. Present
robots Provides crawling and indexing instructions. Present
theme-color Suggests a theme color to supported browsers. Present
Open Graph Provides information for social media previews. Present

3. Meta Tags Explained

Character Encoding

The charset meta tag uses UTF-8 encoding to support a wide range of characters.

Viewport

The viewport tag helps the webpage display correctly on mobile phones, tablets, and computers.

Description

The description tag summarizes the webpage and may be used by search engines in search results.

Robots

The robots tag gives search engines instructions about indexing the page and following its links.

Open Graph

Open Graph properties help control the title, description, and other information shown when a webpage is shared on supported social platforms.

4. Audit Checklist

  • Check that the character encoding is defined.
  • Check that the viewport meta tag is present.
  • Verify that the page title is meaningful.
  • Check that the meta description is relevant.
  • Verify that the author information is correct.
  • Review the robots directive before publishing.
  • Check social-sharing metadata.
  • Remove outdated or unnecessary metadata.

5. Important Notes

The audit table shows the tags included in this example. It does not automatically inspect or validate the HTML document.

The keywords meta tag is generally ignored by major search engines for web ranking. The robots directive should be selected carefully because it can affect how search engines handle a page.
