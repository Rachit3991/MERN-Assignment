1. CSS Position Property

CSS positioning controls where elements appear on a webpage. The position property includes static, relative, absolute, fixed, and sticky.

  • Static: Default positioning in normal document flow.
  • Relative: Positions an element relative to its normal position.
  • Absolute: Positions an element relative to its nearest positioned ancestor.
  • Fixed: Positions an element relative to the viewport.
  • Sticky: Switches between normal flow and sticking to an offset while scrolling.

2. Understanding Z-Index

The CSS z-index property controls the stacking order of overlapping elements. Within the same stacking context, an element with a higher z-index generally appears above one with a lower value.

Example: Box 3 has z-index: 3, Box 2 has z-index: 2, and Box 1 has z-index: 1. Therefore, Box 3 appears on top where they overlap.

3. Design Choices

Hero section: A background image and dark overlay help the white text remain readable.

Positioning: Relative and absolute positioning demonstrate how elements can be placed and layered.

Z-index: Different z-index values show how overlapping elements are stacked.

Responsive design: Media queries adjust spacing and box sizes on smaller screens.

Maintainability: CSS variables make it easier to update colours and border radius.
