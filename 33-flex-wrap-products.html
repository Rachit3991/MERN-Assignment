About This Project

This project demonstrates a responsive product gallery created using HTML, CSS Flexbox, and JavaScript.


CSS Flexbox Properties Used:

  • display: flex; — Arranges product cards using Flexbox.
  • flex-wrap: wrap; — Moves cards to the next row when needed.
  • justify-content: center; — Centers the product cards.
  • align-items: stretch; — Stretches cards along the cross axis.
  • gap: 25px; — Adds spacing between cards.
  • flex: 1 1 230px; — Allows cards to grow and shrink, with a 230px basis.
