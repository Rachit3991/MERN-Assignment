# Assignment 3 – Terminal Navigation Practice Sheet

Answer-A terminal is a text-based interface that allows users to interact with a computer by typing commands. It is useful for creating folders, checking files, and navigating directories during web development.
Terminal navigation helps developers manage project files easily without using a graphical interface.
# Basic Terminal Commands -------
1. cd (Change Directory): Used to check or change the current directory.
2. dir (Directory): Displays the list of files and folders in Windows Command Prompt.
3. mkdir (Make Directory): Creates a new folder.
4. cd foldername: Opens or enters a specified folder.
5. cd ..: Moves back to the parent folder.
6. cls (Clear Screen): Clears the terminal screen in Windows Command Prompt.
# Procedure (In Sequence)------
1. Open the terminal in VS Code.
2. Use the cd command to check the current directory.
3. Use the dir command to view the available files and folders.
4. Use mkdir WebDevelopment to create a new folder.
5. Use cd WebDevelopment to enter the folder.
6. Use mkdir Assignment3 to create an assignment folder.
7. Use cd Assignment3 to enter the assignment folder.
8. Use cd .. to return to the parent folder.
9. Use dir to view the folder contents.
10. Use cls to clear the terminal screen.
