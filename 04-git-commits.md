# Assignment 4 – Repository with at least three meaningful commits

Answer- Git is a version control system used to track changes in files and manage different versions of a project. A repository is a place where project files and their change history are stored.
A commit is a saved snapshot of changes in a repository. Meaningful commits have clear messages that explain what changes were made.
Procedure
1. Install Git on your computer.
2. Open VS Code and create a project folder named MyProject.
3. Open the terminal inside the project folder.
4. Initialize a Git repository using git init.
5. Create an index.html file with basic HTML structure.
6. Add the file to Git using git add ..
7. Make the first commit using git commit -m "Add basic HTML structure".
8. Add a heading to the webpage and make the second commit.
9. Add CSS styling and make the third commit.
10. Use git log --oneline to view the commit history.

commands that has Meaningful commits----
git init
git add .
git commit -m "Add basic HTML structure"
git add .
git commit -m "Add heading to webpage"
git add .
git commit -m "Add CSS styling"
git log --oneline
