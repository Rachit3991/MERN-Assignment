Design Choices

Colour: Deep blue represents trust and professionalism, while orange highlights buttons and interactive elements.

Typography: The system font stack provides fast loading and readable text. A line-height of 1.6 improves readability.

Layout: The content width is limited to 800px to keep the page easy to read. White cards stand out against the light-grey background.

Navigation: Navigation links use HTML fragment identifiers to show different sections without JavaScript or separate HTML files.

Maintainability: CSS variables store the main colours and border radius, making the design easier to update.

Responsive Design: A media query adjusts the header, navigation, and spacing for smaller screens.
