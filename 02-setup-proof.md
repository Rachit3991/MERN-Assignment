# Assignment 2 – Setup Proof (VS Code, Node.js, Live Server)

Answer-1. VS Code Setup
- Download and install Visual Studio Code.
- Open VS Code successfully.
- Create a folder for your web development project.

2. Node.js Setup
- Download and install Node.js from the official website: nodejs.org.
- Open the terminal in VS Code.
- Type the following commands:node -v , npm -v

 3. Live Server Setup
- Open VS Code.
- Go to the Extensions section.
- Search for Live Server and install it.
- Create a file named index.html.
- Right-click the file and select Open with Live Server.
- The webpage should open in your browser.

4. Conclusion
VS Code was used as the code editor, Node.js was verified through 
the terminal, and Live Server was used to run the HTML webpage 
in a browser.
