# Assignment 1 – What happens between typing a URL and seeing the page?

Answer - When we type a URL in a browser, the following steps happen:
1. URL: We enter the website address in the browser.
2. DNS Lookup: DNS finds the IP address of the website.
3. Connection: The browser connects to the website's server.
4. HTTP Request: The browser sends a request to the server.
5. Server Response: The server sends the website's files, such as HTML, CSS, and JavaScript.
6. Rendering: The browser processes these files and displays the webpage on the screen.
Example: When we type www.google.com, the browser follows these steps and displays the Google homepage.
